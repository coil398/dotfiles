# Geminify — Cursor

**対象文**: `$ARGUMENTS`

読みにくい日本語を Gemini 3.8 Flash で読みやすくする。書き直しのあと、その文が原文の意味を誤解していないかを同じモデルで照合する。抜けの棚卸しはしない。

同じターンに質問がある場合は、答えの草稿を内部で作り、その草稿を対象文にする。会話全体は送らない。

## 手順

1. 対象文を決める。`$ARGUMENTS` が本文ならそれを使う。空、または「直前を直して」だけの指定なら、直前のアシスタント出力を使う。
2. 対象文に秘密・資格情報があるなら送らず停止する。
3. このスキルの `scripts/geminify.py` に対象文を `--file` か stdin で渡して実行する。モデル、書き直し、照合はスクリプトが行う。
4. スクリプトの標準出力を、前置きなしでそのまま返す。本文のあとに照合結果が続く。

## 書き直し規則

- 意味・事実・数値・固有名詞・コード・パス・URL・コマンドは変えない
- 情報を足さない。読みにくさの原因になる冗長な接続やメタ説明だけ整える
- AI翻訳調・硬すぎる文体・不自然な体言止めの連続を避ける

## 照合

- 見るのは、書き直しが原文の主張・条件・否定・数値・対象を別の意味に取っていないか
- 意味が同じ言い換えや、意味が変わらない省略は指摘しない
