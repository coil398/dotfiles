# Geminify — Cursor

**対象文**: `$ARGUMENTS`

読みにくい日本語を、今の Cursor モデルで人間向けに書き直す。外部 API・スクリプト・キーは使わない。キーの案内で止めない。

同じターンに質問がある場合は、答えの草稿を内部で作り、答えの内容を欠かさず、この手順で書き直した本文だけを出す。

## 手順

1. 対象文を決める。`$ARGUMENTS` が本文ならそれを使う。空、または「直前を直して」だけの指定なら、直前のアシスタント出力を使う。会話全体は送らない。
2. 対象文に秘密・資格情報があるなら送らず停止する。
3. 親が今のモデルで書き直す。前置き・後書き・解説は出さない。書き直した本文だけを返す。

## 書き直し規則

- 意味・事実・数値・固有名詞・コード・パス・URL・コマンドは変えない
- 情報を足さない。読みにくさの原因になる冗長な接続やメタ説明だけ整える
- AI翻訳調・硬すぎる文体・不自然な体言止めの連続を避ける
