# PIR² 最終サマリー

結果を先に、実際に確認した情報だけを簡潔に示す。

```markdown
## PIR² 完了サマリー

- タスク: [説明]
- 変更ファイル: [実差分で確認した一覧]
- 実装経路: [親の直接実装 / collaboration / その他。実際に使ったものだけ]
- レビュー: [実際に確認した観点と結果。不要なら理由]
- テスト: [実行したコマンド・挙動・結果。不要なら理由]
- 未確認事項・blocker: [なければ none]
- 実装記録・引継ぎ: [実在する場合だけ path]
- 振り返り: [実際の学び。不要なら none]
```

未起動の reviewer/tester の verdict、未生成 artifact、使っていない担当の数値を補完しない。全要件や安全に必要な確認が終わる前に「完了」としない。反復回数や詳細な台帳は判断に役立つ場合だけ示す。refactor-advisor を利用した場合は、ユーザーが選んだ適用内容と残提案を示す。
