# 中断・再開時の作業メモ

長い run やユーザーとの対話で中断する run では、親が次の作業と依存関係を run/artifact に記録してよい。短い run のためにキューを必ず作ったり、固定ステップ・index・担当を先に列挙したりしない。

## 記録する内容

計画から今回扱う実装、レビュー、テスト、確認、引継ぎだけを選び、未完了項目として記録する。直接実装か委譲か、必要な検証、ユーザー判断、実測済みの結果を反映する。未起動の任意工程を固定の未完了項目にしない。

```markdown
## 次の作業

- [ ] [作業] — 前提: [依存または確認事項]

## 完了済み

- [x] [実測済みの作業] — 結果: [確認内容]

## 未確認事項・blocker

- [事項]
```

## 更新と再開

作業完了後に実結果または実在する証拠への参照を追記し、不要と判断した任意工程は理由を残して予定から外す。未実行を検証成功としない。中断後は作業メモと最新の依頼・実差分を照合し、依存が満たされた未完了項目から再開する。

引継ぎを更新する場合も、今回のタスクに属する項目だけを扱う。他タスクの作業や既存のユーザー変更を上書き・削除・revert しない。メモの存在、形式、更新回数だけで作業を停止しない。
