# PIR² 担当への入力境界

この reference は、PIR² の親が担当へ渡す共通境界だけを定めます。担当の役割本文、レビューの進行、判定規則は、親が実体を確認した各 shared skill に委ねます。特定ランタイムの agent 名、通信 API、固定人数、観点一覧をこのファイルへ複製しません。

## 実装担当

親は、目的、確認済み事実、対象版、排他的な書き込み所有、許可・禁止範囲、受入条件、focused check、必要なら実在する計画・記録 path を渡します。担当は親の計画・scope・受入条件を変更せず、別担当のファイルを編集しません。追加調査やユーザー判断が必要なら、推測で決めず親へ返します。

## reviewer への接続

親は shared `reviewer/SKILL.md` に、対象版、要件、ユーザー指定、実在する差分・計画、必要な確認範囲を渡します。shared reviewer が評価者を起動する場合は、評価者へ reviewer の進行手順を渡さず、実体の `code-review-guidance/SKILL.md` の絶対 path と対象に対応する reference だけを渡します。評価者は実在する対象と指定された確認範囲だけを扱い、返却内容には確認した範囲、根拠、未確認、結果を含めます。

## tester への接続

親は shared `tester/SKILL.md` に、対象版、要件、実在する差分、実行者が使う `TEST_SCOPE`、期待結果、禁止範囲を渡します。tester は親が実在を確認した `tester/references/test-procedure.md` と結果契約を使い、未生成の path や未実行結果を補いません。外部状態、権限、費用、不可逆操作が必要なら親へ返します。

## 共通の返却境界

担当は、実際に変更・確認したファイル、コマンドと出力、未確認事項、blocker、必要なら実在する記録 path だけを返します。親は自己申告だけで受入せず、status、diff、検証出力を照合します。失敗後の再実行は、原因と影響範囲が確認できる場合に限り、影響した確認だけを行います。
