# Volume 7

Common type, order and nonmutation rules: [index](INDEX.md).

## line_numbers

U061: `line_numbers(text: str) -> list`

Split with str.splitlines; return lines prefixed with 1-based number followed by colon and one space. No synthetic final line for a trailing newline.

Example: arguments `['a\nb']` → `['1: a', '2: b']`.

## word_lengths

U062: `word_lengths(text: str) -> list`

Return code-point lengths of whitespace-separated words in order.

Example: arguments `['one four']` → `[3, 4]`.

## join_nonempty

U063: `join_nonempty(items: list[str], separator: str) -> str`

Join strings that are not exactly empty; whitespace-only strings are retained.

Example: arguments `[['a', '', 'b'], ',']` → `'a,b'`.

## replace_words

U064: `replace_words(text: str, replacements: dict[str, str]) -> str`

Split on whitespace; replace entire case-sensitive tokens once via replacements and join with one space. Replacement text is not processed again.

Example: arguments `['a b', {'a': 'x'}]` → `'x b'`.

## split_first

U065: `split_first(text: str, separator: str) -> list`

separator is nonempty. Return [before, after] split at first separator; absent yields [text, empty string].

Example: arguments `['a:b:c', ':']` → `['a', 'b:c']`.

## split_last

U066: `split_last(text: str, separator: str) -> list`

separator is nonempty. Return [before, after] split at last separator; absent yields [text, empty string].

Example: arguments `['a:b:c', ':']` → `['a:b', 'c']`.

## truncate

U067: `truncate(text: str, limit: int, marker: str) -> str`

limit is nonnegative. If text length <= limit return unchanged. Otherwise return a prefix plus marker of total length <= limit; if marker exceeds limit return its first limit code points.

Example: arguments `['abcdef', 5, '..']` → `'abc..'`.

## ascii_digits

U068: `ascii_digits(text: str) -> str`

Keep only ASCII characters 0 through 9, in original order.

Example: arguments `['a1b2']` → `'12'`.

## title_tokens

U069: `title_tokens(text: str) -> str`

Split on whitespace; uppercase the first code point and lowercase the remaining substring of each token; join with one space.

Example: arguments `['hELLO wORLD']` → `'Hello World'`.

## char_counts

U070: `char_counts(text: str) -> dict`

Count each Unicode code point, case sensitive, with keys in first encounter order, including whitespace.

Example: arguments `['aba']` → `{'a': 2, 'b': 1}`.
