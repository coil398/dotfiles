# Volume 4

Common type, order and nonmutation rules: [index](INDEX.md).

## prefix_sums

U031: `prefix_sums(items: list[int]) -> list`

Return inclusive running sums in input order.

Example: arguments `[[1, 2, 3]]` → `[1, 3, 6]`.

## differences

U032: `differences(items: list[int]) -> list`

Return next minus previous for every adjacent pair; length below two returns empty.

Example: arguments `[[2, 5, 4]]` → `[3, -1]`.

## sign_counts

U033: `sign_counts(items: list[int]) -> list`

Return [negative count, zero count, positive count].

Example: arguments `[[-1, 0, 2]]` → `[1, 1, 1]`.

## sum_distinct

U034: `sum_distinct(items: list[int]) -> int`

Sum distinct integers, counting each value once; empty returns 0.

Example: arguments `[[1, 2, 1]]` → `3`.

## product_nonzero

U035: `product_nonzero(items: list[int]) -> int`

Multiply nonzero values; if none exist return the empty product 1.

Example: arguments `[[2, 0, 3]]` → `6`.

## weighted_sum

U036: `weighted_sum(values: list[int], weights: list[int]) -> int`

Lists have equal length. Sum pairwise products, preserving duplicate contributions; empty returns 0.

Example: arguments `[[1, 2], [3, 4]]` → `11`.

## gcd_all

U037: `gcd_all(items: list[int]) -> int`

Return nonnegative greatest common divisor of all integers; empty and all-zero input return 0.

Example: arguments `[[12, 18]]` → `6`.

## parity_runs

U038: `parity_runs(items: list[int]) -> int`

Count maximal adjacent runs of equal parity; empty returns 0.

Example: arguments `[[2, 4, 1, 3, 2]]` → `3`.

## argmax_first

U039: `argmax_first(items: list[int]) -> int | None`

Return index of first maximum; empty returns None.

Example: arguments `[[1, 4, 2]]` → `1`.

## nearest_zero

U040: `nearest_zero(items: list[int]) -> int | None`

Return value with smallest absolute value; ties choose the smaller signed value; empty returns None.

Example: arguments `[[-4, 2, 3]]` → `2`.
