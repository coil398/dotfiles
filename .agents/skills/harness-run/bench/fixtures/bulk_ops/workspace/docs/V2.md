# Volume 2

Common type, order and nonmutation rules: [index](INDEX.md).

## stable_unique

U011: `stable_unique(items: list[int]) -> list`

Keep first occurrence of each integer, in encounter order.

Example: arguments `[[3, 1, 3, 2]]` → `[3, 1, 2]`.

## compress_runs

U012: `compress_runs(items: list[int]) -> list`

Keep the first integer of each adjacent equal run, preserving run order.

Example: arguments `[[1, 1, 2, 2, 1]]` → `[1, 2, 1]`.

## chunks

U013: `chunks(items: list[int], size: int) -> list`

size is positive. Return successive list slices of size, keeping a short final slice.

Example: arguments `[[1, 2, 3], 2]` → `[[1, 2], [3]]`.

## windows

U014: `windows(items: list[int], size: int) -> list`

size is positive. Return every full overlapping window of size in start order; omit incomplete windows.

Example: arguments `[[1, 2, 3], 2]` → `[[1, 2], [2, 3]]`.

## interleave

U015: `interleave(left: list[int], right: list[int]) -> list`

Alternate left then right elements while either remains; append the longer tail.

Example: arguments `[[1, 2], [8, 9, 10]]` → `[1, 8, 2, 9, 10]`.

## flatten_once

U016: `flatten_once(rows: list[list[int]]) -> list`

Concatenate rows in row order, flattening exactly one level.

Example: arguments `[[[1, 2], [3]]]` → `[1, 2, 3]`.

## partition_even

U017: `partition_even(items: list[int]) -> list`

Return [evens, odds], preserving encounter order within each list.

Example: arguments `[[3, 2, 1, 4]]` → `[[2, 4], [3, 1]]`.

## move_zeros

U018: `move_zeros(items: list[int]) -> list`

Move all zeros to the end, preserving nonzero order and number of elements.

Example: arguments `[[0, 2, 0, 1]]` → `[2, 1, 0, 0]`.

## take_until

U019: `take_until(items: list[int], stop: int) -> list`

Return elements before the first stop value, excluding it; return all if absent.

Example: arguments `[[1, 2, 3], 2]` → `[1]`.

## drop_until

U020: `drop_until(items: list[int], start: int) -> list`

Return elements starting at the first start value, including it; absent means empty.

Example: arguments `[[1, 2, 3], 2]` → `[2, 3]`.
