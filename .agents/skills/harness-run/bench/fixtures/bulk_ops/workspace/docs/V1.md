# Volume 1

Common type, order and nonmutation rules: [index](INDEX.md).

## slug

U001: `slug(text: str) -> str`

Lowercase ASCII A-Z; keep ASCII a-z and 0-9; replace each maximal run of other characters with one hyphen and strip edge hyphens.

Example: arguments `['Hello World!']` → `'hello-world'`.

## collapse_spaces

U002: `collapse_spaces(text: str) -> str`

Split on Python whitespace and join tokens with one ASCII space.

Example: arguments `[' a  b ']` → `'a b'`.

## strip_prefix

U003: `strip_prefix(text: str, prefix: str) -> str`

Remove one leading prefix if present; empty prefix leaves text unchanged.

Example: arguments `['prepreX', 'pre']` → `'preX'`.

## strip_suffix

U004: `strip_suffix(text: str, suffix: str) -> str`

Remove one trailing suffix if present; empty suffix leaves text unchanged.

Example: arguments `['Xxx', 'x']` → `'Xx'`.

## common_prefix

U005: `common_prefix(left: str, right: str) -> str`

Return the longest shared leading substring, case sensitive.

Example: arguments `['flower', 'flow']` → `'flow'`.

## common_suffix

U006: `common_suffix(left: str, right: str) -> str`

Return the longest shared trailing substring, case sensitive.

Example: arguments `['testing', 'ring']` → `'ing'`.

## mask_tail

U007: `mask_tail(text: str, keep: int) -> str`

keep is a nonnegative integer. Replace all except the last keep code points with *, preserving length; keep=0 masks everything.

Example: arguments `['abcdef', 2]` → `'****ef'`.

## initials

U008: `initials(text: str) -> str`

Take the first code point of each whitespace-separated word, uppercase it using str.upper, and concatenate.

Example: arguments `['ada lovelace']` → `'AL'`.

## escape_pairs

U009: `escape_pairs(text: str) -> str`

Replace each backslash with two backslashes and each vertical bar with backslash-bar; process original characters once.

Example: arguments `['a|b']` → `'a\\|b'`.

## rotate_text

U010: `rotate_text(text: str, offset: int) -> str`

Rotate left by offset modulo length; negative offsets rotate right; empty text returns empty.

Example: arguments `['abcd', 1]` → `'bcda'`.
