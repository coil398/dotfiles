# Volume 6

Common type, order and nonmutation rules: [index](INDEX.md).

## pluck

U051: `pluck(rows: list[dict], key: str, default: int) -> list`

Return row.get(key, default) in row order; row values are integers.

Example: arguments `[[{'x': 1}, {'y': 2}], 'x', 0]` → `[1, 0]`.

## index_last

U052: `index_last(rows: list[dict], key: str) -> dict`

Every row has key with string value. Map that value to a shallow row copy; last row wins, first key position is retained.

Example: arguments `[[{'id': 'a', 'n': 1}, {'id': 'b', 'n': 2}], 'id']` → `{'a': {'id': 'a', 'n': 1}, 'b': {'id': 'b', 'n': 2}}`.

## group_rows

U053: `group_rows(rows: list[dict], key: str) -> dict`

Every row has key with string value. Group shallow row copies by value, retaining first group order and row order including duplicates.

Example: arguments `[[{'k': 'a'}, {'k': 'b'}, {'k': 'a'}], 'k']` → `{'a': [{'k': 'a'}, {'k': 'a'}], 'b': [{'k': 'b'}]}`.

## sort_rows

U054: `sort_rows(rows: list[dict], key: str) -> list`

Every row has key with integer value. Return shallow row copies sorted ascending by key, stable on ties.

Example: arguments `[[{'n': 2}, {'n': 1}], 'n']` → `[{'n': 1}, {'n': 2}]`.

## filter_rows

U055: `filter_rows(rows: list[dict], key: str, value: int) -> list`

Keep shallow row copies whose key exists and equals value; missing keys never match.

Example: arguments `[[{'x': 1}, {'x': 2}, {}], 'x', 1]` → `[{'x': 1}]`.

## sum_column

U056: `sum_column(rows: list[dict], key: str) -> int`

Sum integer values at key; missing keys contribute zero.

Example: arguments `[[{'n': 2}, {'n': 3}, {}], 'n']` → `5`.

## project_rows

U057: `project_rows(rows: list[dict], keys: list[str]) -> list`

Return each row projected to present requested keys, in request order with repeated keys collapsed; retain all rows.

Example: arguments `[[{'a': 1, 'b': 2}, {'b': 3}], ['b', 'a']]` → `[{'b': 2, 'a': 1}, {'b': 3}]`.

## number_rows

U058: `number_rows(rows: list[dict], start: int) -> list`

Copy each row and set _index to start plus its zero-based position, overwriting any existing _index; other key positions remain unchanged.

Example: arguments `[[{'x': 1}, {'x': 2}], 1]` → `[{'x': 1, '_index': 1}, {'x': 2, '_index': 2}]`.

## distinct_rows

U059: `distinct_rows(rows: list[dict], key: str) -> list`

Every row has key with string value. Keep a shallow copy of the first row for each distinct key value in encounter order.

Example: arguments `[[{'k': 'a', 'n': 1}, {'k': 'a', 'n': 2}, {'k': 'b'}], 'k']` → `[{'k': 'a', 'n': 1}, {'k': 'b'}]`.

## transpose_records

U060: `transpose_records(rows: list[dict], keys: list[str], default: int) -> dict`

Return a dict of requested columns in first request order; each list contains row.get(key, default) in row order. Repeated keys collapse.

Example: arguments `[[{'a': 1}, {'b': 2}], ['b', 'a'], 0]` → `{'b': [0, 2], 'a': [1, 0]}`.
