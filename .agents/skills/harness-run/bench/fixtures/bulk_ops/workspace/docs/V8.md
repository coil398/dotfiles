# Volume 8

Common type, order and nonmutation rules: [index](INDEX.md).

## rotate_list

U071: `rotate_list(items: list[int], offset: int) -> list`

Rotate left by offset modulo length, allowing negative offsets; empty returns empty.

Example: arguments `[[1, 2, 3], 1]` → `[2, 3, 1]`.

## explicit_order

U072: `explicit_order(items: list[str], priority: list[str]) -> list`

priority contains unique strings. Sort listed strings by priority, preserving duplicate order, then append unlisted items in original order.

Example: arguments `[['c', 'a', 'b'], ['b', 'a']]` → `['b', 'a', 'c']`.

## intersection

U073: `intersection(left: list[int], right: list[int]) -> list`

Return distinct common values in first left occurrence order.

Example: arguments `[[3, 1, 2], [2, 3]]` → `[3, 2]`.

## difference

U074: `difference(left: list[int], right: list[int]) -> list`

Return all left elements absent from right, retaining left order and duplicates.

Example: arguments `[[1, 2, 3], [2]]` → `[1, 3]`.

## union

U075: `union(left: list[int], right: list[int]) -> list`

Return distinct values in first encounter order across left then right.

Example: arguments `[[2, 1], [1, 3]]` → `[2, 1, 3]`.

## frequencies_sorted

U076: `frequencies_sorted(items: list[int]) -> list`

Return [value,count] pairs sorted by descending count, then ascending numeric value.

Example: arguments `[[2, 1, 2]]` → `[[2, 2], [1, 1]]`.

## run_lengths

U077: `run_lengths(items: list[int]) -> list`

Return [value,count] pairs for adjacent equal runs in input order; separate nonadjacent equal runs.

Example: arguments `[[1, 1, 2, 1]]` → `[[1, 2], [2, 1], [1, 1]]`.

## expand_runs

U078: `expand_runs(runs: list[list[int]]) -> list`

Each run is [integer value, nonnegative count]. Concatenate repeated values in run order; zero count contributes nothing.

Example: arguments `[[[2, 2], [1, 1]]]` → `[2, 2, 1]`.

## zip_fill

U079: `zip_fill(left: list[int], right: list[int], fill: int) -> list`

Return two-element lists at corresponding positions through the longer input; fill missing positions with fill.

Example: arguments `[[1, 2], [3], 0]` → `[[1, 3], [2, 0]]`.

## split_on

U080: `split_on(items: list[int], delimiter: int) -> list`

Split at each delimiter and omit delimiter values. Keep empty segments, including leading/trailing and the one segment of an empty input.

Example: arguments `[[1, 0, 2], 0]` → `[[1], [2]]`.
