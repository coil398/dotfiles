# Volume 5

Common type, order and nonmutation rules: [index](INDEX.md).

## clamp

U041: `clamp(value: int, low: int, high: int) -> int`

low <= high. Return value limited to the inclusive [low, high] interval.

Example: arguments `[5, 0, 3]` → `3`.

## wrap

U042: `wrap(value: int, low: int, high: int) -> int`

low < high. Wrap value into the half-open interval [low, high) using integer modulo.

Example: arguments `[8, 0, 5]` → `3`.

## ceil_div

U043: `ceil_div(value: int, divisor: int) -> int`

divisor is positive. Return the mathematical ceiling of value/divisor as an integer without floats.

Example: arguments `[7, 3]` → `3`.

## round_multiple

U044: `round_multiple(value: int, step: int) -> int`

step is positive. Return nearest multiple of step; ties choose the larger numeric multiple, including for negatives.

Example: arguments `[7, 5]` → `5`.

## interval_overlap

U045: `interval_overlap(a: int, b: int, c: int, d: int) -> int`

a<=b and c<=d. Return length of intersection of half-open intervals [a,b) and [c,d).

Example: arguments `[1, 5, 3, 7]` → `2`.

## split_budget

U046: `split_budget(total: int, count: int) -> list`

total is nonnegative and count positive. Split total into count integers differing by at most one; larger shares come first.

Example: arguments `[8, 3]` → `[3, 3, 2]`.

## pad_right

U047: `pad_right(items: list[int], size: int, fill: int) -> list`

size is nonnegative. Append fill until size is reached; never truncate an already longer list.

Example: arguments `[[1], 3, 0]` → `[1, 0, 0]`.

## trim_edges

U048: `trim_edges(items: list[int], value: int) -> list`

Remove all leading and trailing occurrences of value, preserving interior occurrences.

Example: arguments `[[0, 1, 0, 2, 0], 0]` → `[1, 0, 2]`.

## safe_get

U049: `safe_get(items: list[int], index: int, default: int) -> int`

Use Python negative indexing when in bounds; otherwise return default.

Example: arguments `[[4, 5], 1, 9]` → `5`.

## normalize_slice

U050: `normalize_slice(length: int, start: int, stop: int) -> list`

length is nonnegative. Normalize start and stop like a step-1 Python slice; return [normalized start, normalized stop] without forcing stop >= start.

Example: arguments `[5, -3, 9]` → `[2, 5]`.
