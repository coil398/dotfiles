# Volume 3

Common type, order and nonmutation rules: [index](INDEX.md).

## invert_groups

U021: `invert_groups(mapping: dict[str, str]) -> dict`

Group input keys by their values; group order follows first value occurrence and key order follows encounter order.

Example: arguments `[{'a': 'x', 'b': 'y', 'c': 'x'}]` → `{'x': ['a', 'c'], 'y': ['b']}`.

## select_keys

U022: `select_keys(mapping: dict[str, int], keys: list[str]) -> dict`

Return present requested keys in request order; repeated requests appear only once at their first position.

Example: arguments `[{'a': 1, 'b': 2}, ['b', 'c', 'a']]` → `{'b': 2, 'a': 1}`.

## omit_keys

U023: `omit_keys(mapping: dict[str, int], keys: list[str]) -> dict`

Remove requested keys, retaining remaining insertion order; absent/repeated requests have no effect.

Example: arguments `[{'a': 1, 'b': 2}, ['a']]` → `{'b': 2}`.

## merge_sums

U024: `merge_sums(left: dict[str, int], right: dict[str, int]) -> dict`

Sum values for common keys; key order is left keys then new right keys.

Example: arguments `[{'a': 2}, {'a': 3, 'b': 1}]` → `{'a': 5, 'b': 1}`.

## rename_keys

U025: `rename_keys(mapping: dict[str, int], names: dict[str, str]) -> dict`

Rename using names or keep the original key; on destination collision the last value wins, while the first destination position is retained.

Example: arguments `[{'a': 1, 'b': 2}, {'a': 'x'}]` → `{'x': 1, 'b': 2}`.

## counts

U026: `counts(items: list[str]) -> dict`

Return each string count with keys in first-encounter order.

Example: arguments `[['b', 'a', 'b']]` → `{'b': 2, 'a': 1}`.

## group_lengths

U027: `group_lengths(items: list[str]) -> dict`

Group strings by code-point length, retaining first length occurrence and input order/duplicates within groups.

Example: arguments `[['aa', 'b', 'cc']]` → `{2: ['aa', 'cc'], 1: ['b']}`.

## pairs_last

U028: `pairs_last(pairs: list[list]) -> dict`

Each pair is [string key, integer value]. Make a dict; last value wins but first key position is retained.

Example: arguments `[[['a', 1], ['b', 2]]]` → `{'a': 1, 'b': 2}`.

## sort_values

U029: `sort_values(mapping: dict[str, int]) -> list`

Return keys sorted by ascending value; preserve insertion order for ties.

Example: arguments `[{'a': 3, 'b': 1}]` → `['b', 'a']`.

## dict_delta

U030: `dict_delta(before: dict[str, int], after: dict[str, int]) -> dict`

Return keys present in after that are new or have changed values, in after order. Exclude removed keys.

Example: arguments `[{'a': 1}, {'a': 2, 'b': 3}]` → `{'a': 2, 'b': 3}`.
