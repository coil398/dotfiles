# sync_replay calibration

## Reproduction

Run `python3 private/calibrate.py` from the fixture root. The script uses the exact public and hidden uv commands in the fixed contract, with 300-second subprocess timeouts. Each run gets a fresh copy of workspace; reference runs overlay only private/reference, then copy private/tests into tests_hidden. pytest is the only test dependency. The package uses only stdlib. No model was invoked.

`private/results/summary.json` records per-test outcomes, mutation replacements, exit codes, and all ten repeat totals. Per-run XML and logs are generated by the reproducer. Temporary grading copies are removed on completion.

## Starting implementation and bounds

The starting workspace is derived from the reference with six faults: premature/double acknowledgement, empty-page truncation, omitted terminal acknowledgement, missing global id check, equal-revision acceptance, and deleted revision floors. The first three are in engine.py; the latter three are in state.py. Input validation, source addressing, ownership, and durable publication scaffolding remain functional. No import failure is injected. These fault details are private and are absent from task.md and workspace.

The durable adapters add real file serialization/replace failures and reconstruction to the fake-source/fake-sink scenarios. Reference contains only allowed package paths; it does not contain public tests or rewritten specifications. No bench.py or other fixture was edited and no commit was made.

The workspace is more compact than the approximate 20-file / 1,400-LOC design estimate: it has 13 files and 10 production modules. The estimate is not treated as permission to add filler. The fixed contract acceptance conditions above are measured. Capability bands for real coding models remain unverified; a 25% broken-workspace score does not establish model discrimination.
