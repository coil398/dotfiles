# Antigravity Opus 5.5 前提検証・反証

Antigravity の Claude Opus 5.5 を読み取り専用の反証担当として呼び出し、実装計画・設計方針・検証仮説の盲点を洗い出す。

## 起動

```bash
agy -p --model claude-opus-5-5-high --mode plan \
  "<計画または仮説・対象パス・反証してほしい論点>"
```

## 渡す情報

- 変更対象または検証対象のファイルパス（絶対パス）
- 採用しようとしている方針・計画・仮説の要約
- 特に壊れると困る条件や制約

賛同や言い換えは求めず、次の 4 点だけを実コード・実データの根拠付きで返させる。

1. 前提の誤り: 計画が暗黙に仮定していて、実コードや利用者側と食い違う点
2. 破綻する条件: 境界値、競合、エラー経路、既存利用者への破壊的影響
3. 過剰設計・対症療法: 構造で解くべき箇所を迂回している点、不要な抽象や互換経路
4. 最小の別解: より安全または単純な代替案がある場合のみ、その具体的な差分

## 受入

親は指摘を実コードと照合し、妥当なものだけを計画へ反映してから実装へ進む。
