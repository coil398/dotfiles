# 次ステップキュー

PIR² の中断・再開に必要な残作業を、親が {RUN_DIR}/next-steps.md に記録する。

## 初期化

計画から今回実行する実装・レビュー・確認・引継ぎを選んで checkbox にする。直接実装か委譲か、検証担当を起動するか、どの確認が必要かを反映する。runner の IMPL_INDEX、未起動 refactor-advisor/tester/retrospector、任意の確認待ちを固定の未完了項目として並べない。

例:

- [ ] 対象変更を実装し、差分を照合する
- [ ] 選定した独立レビューを確認する（必要な場合）
- [ ] 対象の再現・回帰確認を実行する
- [ ] 実結果と未完了事項をまとめる

## 更新と再開

ステップ完了後に該当項目を [x] とし、実結果または実在する証拠への参照を残す。中断後はキューと最新依頼を読み、依存が満たされた未完了項目から再開する。

不要と判断した任意工程は理由を記録して予定から外す。未実行を「検証成功」としない。失敗後は影響する項目だけを未完了へ戻し、無関係な完了済み項目を取り消さない。resume時は今回扱うhandoffの残項目を統合し、他タスクの項目を上書きしない。
