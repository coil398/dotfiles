# PIR² 最終サマリー

結果を先に、実際に確認した情報だけを簡潔に示す。

- 何を変更したか。実差分と実在するファイルを参照する。
- 何を検証し、結果がどうだったか。必要なら独立レビューの観点を示す。
- 未完了・未確認・既知の失敗とその影響。
- 実在する実装記録や必要な引継ぎ先。

未起動の tester/reviewer の VERDICT、未生成 artifact、使っていない actor の数値を補完しない。全要件の完了前に「完了」としない。反復回数や詳細な台帳は判断に役立つ場合だけ示す。

refactor-advisor を利用した場合は、ユーザーが選んだ適用内容と残提案を示す。メタ改善推奨がある場合は /retro --meta の判断をユーザーへ委ね、自動実行しない。
